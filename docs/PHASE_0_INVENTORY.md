### Recommendation for Phase 2

**Do not use `@theia/ai-*` provider stack for Soriku integration.** The bootstrap prompt requires a thin, replaceable engine client talking to the Soriku headless backend. Theia's built-in AI layer is provider-centric (OpenAI, Anthropic, etc.) and conflicts with the model-agnostic principle.

Build `extensions/soriku-*` with native `fetch` + `EventSource` instead. Theia primitives (`@theia/core`, `@theia/filesystem`, `@theia/task`, `@theia/workspace`) only.
